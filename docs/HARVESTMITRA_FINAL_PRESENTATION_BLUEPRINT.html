4 Judge Q&A Defense Strategy

Q1: "How do you handle zero internet connectivity in remote villages?" Varun
"We built a dual-layer offline architecture: Sayali's frontend caches recent mandi rates and checklists in LocalStorage via our Network Badge, while my backend uses a local deterministic rule engine so Mitra AI answers without needing external cloud APIs."
Q2: "What prevents AI from hallucinating incorrect mandi rates?" Prashant
"Generative AI never calculates financial projections in our app. All revenue and cost formulas are executed by my strict mathematical engine (`mathEngine.js`) connected to verified APMC MySQL records."
Q3: "How secure is your platform against unauthorized access?" Mihir
"We implemented JWT token authentication with role-based access control. Admin endpoints return 403 Forbidden to farmers, passwords use bcrypt hashing with 10 salt rounds, and all guest sessions are sandboxed."
Q4: "Can non-English speaking farmers use this effectively?" Sayali
"Yes, our design system offers full multilingual support across Marathi, Hindi, Gujarati, and English, coupled with Web Speech STT/TTS and high-contrast visual charts so literacy is never a barrier."
