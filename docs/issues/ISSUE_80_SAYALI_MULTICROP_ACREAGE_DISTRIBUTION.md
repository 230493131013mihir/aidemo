## 📌 Feature Description
Allow farmers who cultivate multiple crops (e.g. Cotton, Wheat, Mustard) to switch crops interactively on the Dashboard and view their farm acreage distribution in an animated Recharts donut chart.

### Technical Implementation:
- Built a dynamic crop tab switcher in `DashboardPage.jsx`.
- Integrated interactive Recharts Donut / Pie chart displaying acreage distribution.
- Real-time gross and net revenue recalculations when switching between active crops.
- Fully responsive mobile design with 0 horizontal overflow.
